# Booster 3v3 Soccer Agent

当前版本为 **1.3.0**，基于 Booster 官方简单框架。策略包含两次触球开球、门将主动拦截、射门／传球／带球决策和防无活动罚下。用 Booster Studio 打开仓库根目录即可构建 `.agent`。

# How to use
1. Download [Booster Studio](https://studio.booster.tech/)
2. Open the repository root in Booster Studio
3. Wait for the environment to finish setting up
4. Select a virtual robot
5. Click "Activate, build, deploy and run agent"
